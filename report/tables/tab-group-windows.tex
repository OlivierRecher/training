\figtext{%
\figpara{Where these hours come from.}{They are not chosen. For each kind of user
I take the score of the one-line rule hour by hour \emph{on that kind alone}, and
keep the run of consecutive hours where it falls furthest below that kind's own
average: the hours at which ``repeat the last antenna'' stops working \emph{for
that sort of person}. The multiplier says how much more a mistake costs there. The
first row is what a hand-made rule could never produce, since the stay-at-home
user gets no emphasised hours at all, and the last two rows are almost disjoint in
time.}

\figpara{The lower block is the test that justifies the whole detour.}{An
emphasised stretch is only useful if it lands on hard moments. The guess of
Chapter~\ref{ch:time} separates the rule by two tenths, which is to say not at
all. The hours derived per kind of user separate it by 27.4, marking moments on
which the trivial rule is right 19\,\% of the time against 46\,\% elsewhere.
Worse, the guess was misplaced rather than merely imprecise: 04--06h is
\emph{easier} than average for all four kinds.}}
