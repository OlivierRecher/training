\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
\thispagestyle{plain}

Mobile terminals continuously attach to cellular antennas, with operators logging transitions as discrete event logs. This report evaluates whether parameter-efficient fine-tuned language models trained on anonymized call detail records can forecast a subscriber's next cellular antenna attachment superior to a deterministic benchmark. Predictions are evaluated against the \emph{persistence baseline} (\emph{``the next cell matches the current cell''}), which achieves an accuracy of 69.2\% on unfiltered daily logs due to subscriber stationary intervals and serves as the primary benchmark across all experimental evaluations.

The empirical dataset comprises fifteen daily logs from the Karlovy Vary study area, encompassing 369 cells mounted across 113 base stations. On a held-out test cohort of 1,000 subscribers, the fine-tuned model achieves a \textbf{+4.3 percentage point accuracy gain} over the persistence baseline (54.5\% vs. 50.2\% top-1 accuracy). Surpassing the persistence baseline required conditioning parameter updates on \emph{subscriber temporal mobility profiles}, stratifying users into behavioral cohorts and routing trajectories to specialized LoRA parameter adapters. Experimental results demonstrate that cohort scaling saturates at approximately 2,000 subscribers (+4.2 percentage points over baseline), while individual subscriber mobility typology accounts for a 22.4 percentage point accuracy spread across behavioral groups (compared to 0.4 percentage points across dataset scale). Trajectory predictability is fundamentally governed by subscriber mobility patterns rather than training dataset volume.

\vspace{0.8em}
\noindent\textbf{Keywords:} human mobility prediction, call detail records,\footnote{\textbf{CDR}, \emph{call detail record}: an anonymized network event log containing subscriber identifier, event timestamp, and attached cell identifier, excluding communication content.} next-cell prediction, large language models, LoRA, QLoRA, behavioral clustering, trajectory scaling.
