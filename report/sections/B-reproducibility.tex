\chapter{Reproducibility}
\label{app:repro}

To ensure full experimental reproducibility, this appendix documents the hyperparameter configurations, data provenance mappings, and core decision-encoding parameters across all eleven experimental iterations. 

\textbf{Table~\ref{tab:hyperparams}} records the exact hyperparameter settings across four chronological run families (Iter.\ 1, Iter.\ 2--6, Iter.\ 7--9, and Iter.\ 10--11). All unlisted hyperparameters were held strictly constant across runs, ensuring that performance variations stem exclusively from data preprocessing, sequence formatting, or adapter conditioning mechanisms rather than hyperparameter tuning artifacts. Key parameters include max pass caps (20 epochs) with early stopping (patience 4), implementing the validation checkpoint selection protocol established in \textbf{Chapter~\ref{ch:tools}}, and transition sampling emphasis shifting from global hours to subgroup-specific temporal profiles (\textbf{Chapters~\ref{ch:time}} and \textbf{\ref{ch:groups}}).

Altering any of these eleven keys explicitly modifies an empirical claim or scope constraint established in this report.
