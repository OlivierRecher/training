\paragraph{Research Objective.} Predict the next cell attachment for a mobile phone trajectory based exclusively on the historical sequence of observed cell events. Accurate next-cell prediction enables mobile network operators to optimize network capacity allocation and reduce handover connection drops.

\paragraph{Dataset Characterization.} Evaluation uses fifteen daily logs from a Czech mobile operator covering the Karlovy Vary study area (12--26 March 2014), comprising 369 cells mounted on 113 base stations across 80,217 to 99,504 daily user trajectories. Records contain anonymized user identifiers, event timestamps, and cell IDs, excluding personal data or message content.

\paragraph{Benchmark Reference Baseline.} Predictions are evaluated against the \textbf{persistence baseline} (\emph{``the next cell is identical to the current cell''}). On raw daily logs, this baseline achieves 69.2\% accuracy due to high user stationary time. Model performance is reported exclusively as accuracy deltas relative to this baseline benchmark.

\paragraph{Model Architecture.} A 500M-parameter language model (Qwen2.5-0.5B-Instruct) is fine-tuned using Quantized Low-Rank Adaptation (QLoRA) on single GPU instances, adapting discrete language representations to spatial transition modeling.

\paragraph{Experimental Chronology.} \textbf{Table~\ref{tab:recap}} summarizes the experimental progression across eleven iterations, detailing cohort characteristics, architectural modifications, and baseline accuracy deltas (\textbf{Gap} column). The \textbf{Persistence baseline} column, the baseline's own score, moves from row to row, which is why the absolute scores may not be compared across rows: test user filtering and evaluation protocols changed four times across project stages (for instance, shifting from grading the ``last fifth'' of a day to grading the harder ``whole day'' sequence lowers baseline accuracy from 45.5\% to 43.1\% on identical user data), so cross-iteration comparisons are valid only on relative baseline deltas. Early iterations (1--3, 5--7) operated below baseline, Iteration 4 produced a transient gain (+1.1\,\%) resolved by subsequent filtering, and sustained baseline outperformance (+3.7\,\% to +4.3\,\%) was established from Iteration 8 onward with per-group LoRA adapter routing. Iteration 9 occupies two rows because two independent changes were tested that week; Appendix~\ref{app:timeline} details what each iteration did.

\paragraph{Key Research Findings.}
\begin{enumerate}
\item \textbf{Baseline Outperformance via User Stratification}: The fine-tuned language model achieves a \textbf{+4.3\,\% top-1 accuracy gain} over the persistence baseline on held-out evaluation cohorts (54.5\% vs. 50.2\% top-1 accuracy). Surpassing the persistence baseline required stratifying users into temporal mobility profiles ($G0$--$G3$) and routing trajectories to per-group LoRA adapters (Chapter~\textbf{\ref{ch:groups}}).
\item \textbf{Data Cohort Scaling Saturation at 2,000 Users}: Accuracy gains saturate at approximately 2,000 users (+4.2\,\% over baseline). Expanding training cohorts to 21,000 users yields no statistically significant improvement (+0.04\,\%, $p > 0.05$) (Chapter~\textbf{\ref{ch:scale}}).
\item \textbf{Dominance of User Typology over Data Scale}: Individual user mobility typology accounts for a \textbf{22.4\,\% accuracy spread} across behavioral groups, exerting a $50\times$ stronger influence on predictability than scaling dataset size beyond 2,000 users (Chapters~\textbf{\ref{ch:user}} and \textbf{\ref{ch:scale}}).
\end{enumerate}

\paragraph{Methodological Insights.} Experimental evaluations established key methodological principles: applying early stopping at peak validation accuracy prevents overfitting (+15.5\,\% accuracy recovery over final epoch checkpoints); standardizing context fraction split protocols prevents evaluation split artifacts; and benchmarking on active mobility cohorts ensures meaningful performance measurement (Chapter~\textbf{\ref{ch:tools}}).
