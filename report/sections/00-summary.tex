\paragraph{Research Objective.} Predict the next cellular antenna attachment for a mobile phone trajectory based exclusively on the historical sequence of observed cell events. Accurate next-cell prediction enables mobile network operators to optimize network capacity allocation and reduce handover connection drops.

\paragraph{Dataset Characterization.} Evaluation uses fifteen daily logs from a Czech mobile operator covering the Karlovy Vary study area (12--26 March 2014), comprising 369 cells mounted on 113 base stations across 80,217 to 99,504 daily subscriber trajectories. Records contain anonymized subscriber identifiers, event timestamps, and cell IDs, excluding personal data or message content.

\paragraph{Benchmark Reference Baseline.} Predictions are evaluated against the \textbf{persistence baseline} (\emph{``the next cell is identical to the current cell''}). On raw daily logs, this baseline achieves 69.2\% accuracy due to high subscriber stationary time. Model performance is reported exclusively as accuracy percentage point deltas relative to this baseline benchmark.

\paragraph{Model Architecture.} A 500M-parameter language model (Qwen2.5-0.5B-Instruct) is fine-tuned using Quantized Low-Rank Adaptation (QLoRA) on single GPU instances, adapting discrete language representations to spatial transition modeling.

\paragraph{Key Research Findings.}
1. \textbf{Baseline Outperformance via User Stratification}: The fine-tuned language model achieves a \textbf{+4.3 percentage point top-1 accuracy gain} over the persistence baseline on held-out evaluation cohorts (54.5\% vs. 50.2\% top-1 accuracy). Surpassing the persistence baseline required stratifying subscribers into temporal mobility profiles ($G0$--$G3$) and routing trajectories to per-group LoRA adapters (Chapter~\textbf{\ref{ch:groups}}).
2. \textbf{Data Cohort Scaling Saturation at 2,000 Subscribers}: Accuracy gains saturate at approximately 2,000 subscribers (+4.2 percentage points over baseline). Expanding training cohorts to 21,000 subscribers yields no statistically significant improvement (+0.04 percentage points, $p > 0.05$) (Chapter~\textbf{\ref{ch:scale}}).
3. \textbf{Dominance of Subscriber Typology over Data Scale}: Individual subscriber mobility typology accounts for a \textbf{22.4 percentage point accuracy spread} across behavioral groups, exerting a $50\times$ stronger influence on predictability than scaling dataset size beyond 2,000 subscribers (Chapters~\textbf{\ref{ch:user}} and \textbf{\ref{ch:scale}}).

\paragraph{Methodological Insights.} Experimental evaluations established key methodological principles: applying early stopping at peak validation accuracy prevents overfitting (+15.5 percentage point accuracy recovery over final epoch checkpoints); standardizing context fraction split protocols prevents evaluation split artifacts; and benchmarking on active mobility cohorts ensures meaningful performance measurement (Chapter~\textbf{\ref{ch:tools}}).
