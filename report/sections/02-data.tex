\chapter{Dataset Analysis and Preprocessing}
\label{ch:data}

\section{Data Analysis Objectives}

Prior to model training, the structural characteristics of the mobile network logs must be thoroughly analyzed. Two fundamental properties constrain all subsequent experiments: a network log event does not necessarily imply spatial displacement, and an individual cell identifier does not uniquely define a geographical site. These structural features account for several non-intuitive empirical findings presented in later chapters.

\section{Structure of the Records}

The empirical evaluation uses fifteen daily log files spanning 12 to 26 March 2014 from the Karlovy Vary study area in north-west Bohemia. The dataset consists of comma-separated values (CSV) files, where \textbf{each line represents a single user's 24-hour activity trace} from 00:00:00 to 23:59:59. Depending on the specific day, daily files contain between 80,217 and 99,504 user trajectories; the primary benchmark dataset from 12 March 2014 comprises 85,946 users.

Each record row begins with eight metadata columns followed by a sequence of timestamped cell interaction pairs. The initial columns indicate an anonymized user ID, age, gender, an administrative code, a behavioral category, a designated home cell ID, an activity cell ID, and the total event count. Following the metadata header, trajectory entries consist of \textbf{a cell identifier string paired with an event timestamp} expressed in elapsed seconds since midnight ($0 \le t \le 86,399$). Model training exclusively utilizes the user ID, total event count, and timestamped cell identifier sequence; remaining metadata fields contain recorded anomalies (such as invalid age values) and were excluded.

Network log events are registered whenever a mobile terminal interacts with a base station, including automatic periodic network polling. Base stations initiate periodic location updates on fixed time intervals (typically every 4 hours on 2G networks and every 2 hours on 3G networks) to track active devices for incoming call routing. Consequently, \textbf{a network record does not imply physical movement}: a stationary user generates periodic events throughout the day. Conversely, \textbf{records are not hourly and not evenly spaced}: a user may leave several records within a few minutes and then none for several hours. How many records a user leaves, and when, depends on how the phone connects to the network (calls, messages, data sessions, periodic updates) and on its radio generation, not on a fixed clock. Contiguous sequences of identical cell identifiers account for the high baseline performance of the persistence rule. \textbf{Figure~\ref{fig:record-day}} shows both facts on one day.

\subsection{Baseline Performance and Population Dependencies}

The \textbf{persistence baseline} evaluates the prediction heuristic stating that the next cell identifier matches the most recent observed cell identifier. This deterministic baseline is evaluated across identical trajectory points and evaluation protocols as the fine-tuned language models.

Crucially, the accuracy of the persistence baseline is not fixed; it is a parameter of the evaluated population cohort. On unfiltered daily logs containing a high proportion of stationary users, the persistence baseline achieves 69.2\% accuracy. When the dataset is filtered to include only active mobile users, baseline performance drops to 45.5\%. The underlying baseline heuristic remains unchanged while the population mobility characteristics shift.

\section{Distinction Between Base Stations and Logical Cells}

Cell identifiers such as \cid{BKVCHE1} represent logical network coverage sectors rather than physical site coordinates. In technical documentation, this string is designated as the \textbf{\cid{cell\_id}}.

\textbf{Figure~\ref{fig:base-station}} illustrates the spatial mapping of a single physical base station to its associated cell identifiers, viewed from above. The central crossed circle represents the physical installation, while each shaded lobe corresponds to the spatial coverage area of one cell. A single base station serves multiple cells across different radio frequencies and sectors. \textbf{\panelref{fig:base-station}{a}} illustrates a 2G configuration operating four directional sector cells, while \textbf{\panelref{fig:base-station}{b}} adds four 3G directional cells with distinct frequency ranges and spatial orientations. Because all eight coverage lobes originate from a single physical base station location, a stationary device at the foot of the base station sits inside multiple overlapping coverage sectors simultaneously. Radio signal fluctuations can trigger network handovers between adjacent directional sectors or frequency bands, which register in raw network logs as cell transitions despite zero user spatial movement. \textbf{Figure~\ref{fig:transition-composition}} measures how often this happens.

\textbf{Figure~\ref{fig:transition-composition}} takes every pair of consecutive records of \textbf{a single day} of data. The upper bar (\Draw{}) is that day file taken as it comes; the lower bar (\Dmob{}) is not new data but a reworked version of a day file, in which only the users who genuinely move were kept (Section~\ref{sec:data-sets}). Each bar is 100\% of its pairs, split into three structural categories:
\begin{enumerate}
  \item \textbf{Same Cell ID} (dark blue): consecutive events log identical cell identifiers, indicating stationary temporal residence.
  \item \textbf{Same Base Station, Different Cell ID} (teal): consecutive events log different cell identifiers mounted on the same physical base station, representing radio sector handovers without spatial displacement.
  \item \textbf{Different Base Station} (orange): consecutive events log a transition to a different base station site, representing true physical user mobility.
\end{enumerate}
On an unfiltered raw day file (\Draw{}), only 44.0\% of consecutive event pairs represent physical spatial displacement, while \textbf{12.4 out of every 100} are same-base-station sector handovers that look like movement in the raw data and are not. Filtering the corpus to active mobile users (\Dmob{}) increases the proportion of true physical movement to 51.0\%, while intra-site sector handovers remain constant at 12.0\%. This constancy confirms that intra-site sector handovers are an intrinsic property of the radio cellular infrastructure rather than individual user behavior. To accurately evaluate physical mobility, displacement analyses in this report assess movement at the base station level, while the model prediction target remains the full \cid{cell\_id} string; the cost of that choice is examined in Chapter~\ref{ch:user}.

\section{Data Preprocessing and Dataset Construction}
\label{sec:data-sets}

\textbf{Figure~\ref{fig:data-flow}} details the four-stage data preprocessing pipeline that transforms one raw daily record, as described above, into formatted training sequences:
\begin{enumerate}
  \item \textbf{Trajectory Extraction}: of the eight header columns, only the user identifier (\cid{user\_id}) is kept, together with the cell attachment sequence and its event timestamps.
  \item \textbf{Temporal Token Prepending}: event timestamps are converted into explicit hourly tokens (\cid{<H00>}--\cid{<H23>}) prepended to each cell identifier.
  \item \textbf{User Sequence Assembly}: single-user daily attachment records are formatted into ordered sequence strings.
  \item \textbf{Stratified Population Split}: users are partitioned into disjoint training and held-out test cohorts prior to model training.
\end{enumerate}
As depicted by the separate training and test circles, partitioning is performed strictly by user ID, ensuring no individual appears in both splits and preventing memorization leakage. Trajectory volume stratification ensures both cohorts maintain identical distributions of short and long daily histories.

\section{Scope and Methodological Limitations}

\paragraph{Temporal Boundary: Intra-Day Predictions.} The primary task evaluated in this report is intra-day trajectory prediction: forecasting the remaining segment of a user's daily trajectory given its initial prefix. Inter-day forecasting across consecutive days represents a distinct problem scope.

\paragraph{Spatial Coverage and Cell Densities.} The geographical study region encompasses 369 cells across 113 base stations, with individual users visiting an average of twenty unique cells. At small training sizes (400 users), 98.9\% of cell IDs in the test set were present in the training set; at training sizes of 5,000 users and above, vocabulary coverage reaches 100\%. Consequently, out-of-vocabulary cell generation is not a limiting factor for larger datasets, meaning performance gains must derive from modeling transition probabilities between known cells.

\section{Conclusion}
\label{sec:retro-data}

Two structural properties of the records dictate the empirical results presented in this report. First, a network log event does not necessarily signify physical spatial displacement; periodic location updates produce repeated entries during stationary periods, establishing a high persistence baseline score. Second, cell identifiers represent sectors of a base station rather than unique physical locations, with 12.4\% of cell transitions occurring across sectors of the same physical base station (\textbf{Figure~\ref{fig:transition-composition}}). Consequently, physical mobility analyses in this report evaluate base station site transitions, while the predictive model target maintains granular cell ID resolution.

Filtering the dataset to active mobile users removed trivial stationary trajectories and established a meaningful evaluation benchmark. Although late data filtering necessitated the six experimental dataset cohorts documented in \textbf{Table~\ref{tab:datasets}}, reporting performance gains relative to the persistence baseline ensures consistent comparative analysis across all experimental phases.
