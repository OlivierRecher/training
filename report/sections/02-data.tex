\chapter{Dataset Analysis and Preprocessing}
\label{ch:data}

\section{Data Analysis Objectives}

Prior to model training, the structural characteristics of the mobile network logs must be thoroughly analyzed. Two fundamental properties constrain all subsequent experiments: \textbf{a network log event does not necessarily imply spatial displacement}, and \textbf{an individual cell identifier does not uniquely define a geographical site}. These structural features account for several non-intuitive empirical findings presented in later chapters.

\section{Structure of Call Detail Records}

The empirical evaluation uses fifteen daily log files spanning 12 to 26 March 2014 from the Karlovy Vary study area in north-west Bohemia. The dataset consists of comma-separated values (CSV) files, where \textbf{each line represents a single subscriber's 24-hour activity trace} from 00:00:00 to 23:59:59. Depending on the specific day, daily files contain between 80,217 and 99,504 subscriber trajectories; the primary benchmark dataset from 12 March 2014 comprises 85,946 subscribers.

Each record row begins with eight metadata columns followed by a sequence of timestamped cell interaction pairs. The initial columns indicate an anonymized subscriber ID, age, gender, an administrative code, a behavioral category, a designated home cell ID, an activity cell ID, and the total event count. Following the metadata header, trajectory entries consist of \textbf{a cell identifier string paired with an event timestamp} expressed in elapsed seconds since midnight ($0 \le t \le 86,399$). Model training exclusively utilizes the subscriber ID, total event count, and timestamped cell identifier sequence; remaining metadata fields contain recorded anomalies (such as invalid age values) and were excluded.

Network log events are registered whenever a mobile terminal interacts with a base station mast, including automatic periodic network polling. Base stations initiate periodic location updates on fixed time intervals (typically every 4 hours on 2G networks and every 2 hours on 3G networks) to track active devices for incoming call routing. Consequently, \textbf{a network record does not imply physical movement}: a stationary subscriber generates periodic events throughout the day. The number of generated logs depends on the radio network generation as well as physical subscriber behavior. Contiguous sequences of identical cell identifiers account for the high baseline performance of the persistence rule.

\subsection{Baseline Performance and Population Dependencies}

The \textbf{persistence baseline} evaluates the prediction heuristic stating that the next cell identifier matches the most recent observed cell identifier. This deterministic baseline is evaluated across identical trajectory points and evaluation protocols as the fine-tuned language models.

Crucially, the accuracy of the persistence baseline is not fixed; it is a parameter of the evaluated population cohort. On unfiltered daily logs containing a high proportion of stationary subscribers, the persistence baseline achieves 69.2\% accuracy. When the dataset is filtered to include only active mobile subscribers, baseline performance drops to 45.5\%. The underlying baseline heuristic remains unchanged while the population mobility characteristics shift.

\section{Distinction Between Physical Masts and Logical Cells}

Cell identifiers such as \cid{BKVCHE1} represent logical network coverage sectors rather than physical site coordinates. In technical documentation, this string is designated as the \textbf{\cid{cell\_id}}.

\input{figures/fig-base-station}

\textbf{Figure~\ref{fig:base-station}} illustrates the spatial mapping of a single physical base station mast to its associated cell identifiers, viewed from above. The central crossed circle represents the physical installation, while each shaded lobe corresponds to the spatial coverage area of a directional antenna. A single physical site operates multiple directional antennas operating across different radio frequencies and sectors. \textbf{\panelref{fig:base-station}{a}} illustrates a 2G configuration operating four directional sector cells, while \textbf{\panelref{fig:base-station}{b}} adds four 3G directional cells with distinct frequency ranges and spatial orientations. Because all eight coverage lobes originate from a single physical mast location, a stationary device at the foot of the mast sits inside multiple overlapping coverage sectors simultaneously. Radio signal fluctuations can trigger network handovers between adjacent directional sectors or frequency bands, which register in raw network logs as cell transitions despite zero subscriber spatial movement. On the primary benchmark dataset, such intra-site sector handovers account for \textbf{12.4 out of every 100} consecutive records.

\input{figures/fig-transition-composition}

\textbf{Figure~\ref{fig:transition-composition}} quantifies the distribution of consecutive record pairs across three distinct structural categories:
1. \textbf{Same Cell ID} (dark blue): consecutive events log identical cell identifiers, indicating stationary temporal residence.
2. \textbf{Same Mast, Different Cell ID} (teal): consecutive events log different cell identifiers mounted on the same physical base station mast, representing radio sector handovers without spatial displacement.
3. \textbf{Different Mast} (orange): consecutive events log a transition to a different base station site, representing true physical subscriber mobility.

As shown in \textbf{Figure~\ref{fig:transition-composition}}, on an unfiltered raw day file (\Draw{}), only 44.0\% of consecutive event pairs represent physical spatial displacement, while 12.4\% represent same-mast sector handovers. Filtering the corpus to active mobile subscribers (\Dmob{}) increases the proportion of true physical movement to 51.0\%, while intra-site sector handovers remain constant at 12.0\%. This constancy confirms that intra-site sector handovers are an intrinsic property of the radio cellular infrastructure rather than individual subscriber behavior. To accurately evaluate physical mobility, displacement analyses in this report assess movement at the base station mast level, while the model prediction target remains the full antenna \cid{cell\_id} string.

\section{Data Preprocessing and Dataset Construction}

\input{figures/fig-data-flow}

\textbf{Figure~\ref{fig:data-flow}} details the four-stage data preprocessing pipeline used to transform raw network logs into formatted training sequences:
1. \textbf{Trajectory Extraction}: administrative header metadata columns are stripped, retaining only cell attachment sequences and event timestamps.
2. \textbf{Temporal Token Prepending}: event timestamps are converted into explicit hourly tokens (\cid{<H00>}--\cid{<H23>}) prepended to each cell identifier.
3. \textbf{Subscriber Sequence Assembly}: single-subscriber daily attachment records are formatted into ordered sequence strings.
4. \textbf{Stratified Population Split}: subscribers are partitioned into disjoint training and held-out test cohorts prior to model training.

As depicted by the separate training and test circles in \textbf{Figure~\ref{fig:data-flow}}, partitioning is performed strictly by subscriber ID, ensuring no individual appears in both splits and preventing memorization leakage. Trajectory volume stratification ensures both cohorts maintain identical distributions of short and long daily histories.

\subsection{Characteristics of Experimental Cohorts}

\input{tables/tab-datasets}

\textbf{Table~\ref{tab:datasets}} summarizes the six experimental dataset cohorts created during this study, detailing training and evaluation subscriber counts, average daily record volume per subscriber, and corresponding persistence baseline accuracy scores. The creation of distinct dataset cohorts resulted from evolving research requirements across experimental iterations: incorporating hourly features required regenerating token sequences with temporal tags; evaluating population scaling required larger single-day extractions; and multi-day scaling required concatenating eleven distinct daily logs. 

Crucially, the baseline score column in \textbf{Table~\ref{tab:datasets}} shifts due to changes in subscriber population mobility characteristics rather than modifications to the baseline definition itself. The single-line persistence rule remains identical across all cohorts; its accuracy varies because subscriber mobility distributions differ. Consequently, raw accuracy scores from different dataset cohorts must never be compared directly; all performance gains must be evaluated relative to the baseline of their respective cohort. For \Dmob{}, \textbf{Table~\ref{tab:datasets}} reports two baseline scores: 45.5\% evaluated on the final 20\% prefix context split, and 43.1\% evaluated sequentially across all trajectory positions (a harder benchmark introduced in the sixth iteration).

\section{Scope and Methodological Limitations}

\paragraph{Temporal Boundary: Intra-Day Predictions.} The primary task evaluated in this report is intra-day trajectory prediction: forecasting the remaining segment of a subscriber's daily trajectory given its initial prefix. Inter-day forecasting across consecutive days represents a distinct problem scope.

\paragraph{Spatial Coverage and Antenna Densities.} The geographical study region encompasses 369 cells across 113 base stations, with individual subscribers visiting an average of twenty unique cells. At small training sizes (400 subscribers), 98.9\% of cell IDs in the test set were present in the training set; at training sizes of 5,000 subscribers and above, vocabulary coverage reaches 100\%. Consequently, out-of-vocabulary cell generation is not a limiting factor for larger datasets, meaning performance gains must derive from modeling transition probabilities between known cells.

\section{Conclusion}
\label{sec:retro-data}

Two structural properties of cell detail records dictate the empirical results presented in this report. First, a network log event does not necessarily signify physical spatial displacement; periodic location updates produce repeated entries during stationary periods, establishing a high persistence baseline score. Second, cell identifiers represent sectorized antennas rather than unique physical locations, with 12.4\% of cell transitions occurring across sectors of the same physical mast (\textbf{Figure~\ref{fig:transition-composition}}). Consequently, physical mobility analyses in this report evaluate base station site transitions, while the predictive model target maintains granular cell ID resolution.

Filtering the dataset to active mobile subscribers removed trivial stationary trajectories and established a meaningful evaluation benchmark. Although late data filtering necessitated the six experimental dataset cohorts documented in \textbf{Table~\ref{tab:datasets}}, reporting performance gains relative to the persistence baseline ensures consistent comparative analysis across all experimental phases.
