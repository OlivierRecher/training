\caption{What this internship built, in four steps}
\label{fig:overview}
\figtext{%
\figpara{What the picture says.}{The mobile network records, all day, which
antenna each phone is attached to. I turn one person's day into a plain ordered
list, retrain a small language model on thousands of those lists, and ask it to
continue one: it names which antenna the person will be on next by ranking all
369 antennas of the area. A language model fits a question with no language in
it because the shape is the same, an ordered list of symbols drawn from a fixed
set. The dashed box is the real difficulty: a competitor with no model at all,
``the person is still where they were'', is already right about seven times out
of ten, and every number in this report is the distance to it.}}
