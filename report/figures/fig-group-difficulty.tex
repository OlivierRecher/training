\caption[Group difficulty and group detectability]{(a)~The group label is not
merely descriptive: it says in advance how hard a user will be. G0 changes site
about a third of the time and ``repeat the last cell'' is already right 56.3\,\%
of the time for them; G3 changes site half again as often and the same rule is
right only 17.8\,\% of the time. (b)~At inference only a user's past exists, so
the group must be computed from the context prefix and never from the target.
At the reference 80\,\% context the pipeline recovers the right group 92 times
out of 100 unaided; below roughly 60\,\% of the day there is not enough history
to tell the profiles apart, which is what the two pale bars mean. \smob,
400 train / 100 test users.}
